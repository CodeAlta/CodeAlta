# Returns

The back office applies these rules when a customer asks to return an item.

## Policy

- A return is accepted within 30 days of delivery when the item is unused and in its original packaging, except for perishable goods, which cannot be returned, and for items bought on sale, which can only be exchanged, and the customer pays the shipping unless the item arrived damaged, in which case the shop sends a prepaid label.
- Refunds are issued within 5 working days of the reception of the item.
