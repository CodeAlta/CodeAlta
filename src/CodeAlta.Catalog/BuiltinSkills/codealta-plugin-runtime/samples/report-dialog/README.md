# Report dialog sample

Its `/report` command opens a dialog with a table, a flowchart and a block of C# code. It shows how a fragment uses what the window of CodeAlta Desktop draws itself: `PluginHtml.Markdown` for Markdown, `PluginHtml.Diagram` for a Mermaid diagram and `PluginHtml.Code` for highlighted code. CodeAlta TUI shows the same report as text.
