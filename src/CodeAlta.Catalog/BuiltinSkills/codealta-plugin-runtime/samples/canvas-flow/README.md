# Canvas flow sample

A tab that draws a graph with React Flow (`@xyflow/react`), with the data in the plugin. `plugin.cs` declares one canvas, `flow`, whose view names a script of the package folder (`PluginScript.File("ui/flow.js")`): the steps of a release pipeline and the links between them. It registers what the script calls on `canvas.Rpc`: `flow.watch` (a stream: the pipeline now, then after each change), `flow.move`, `flow.connect`, `flow.disconnect`, `flow.status`, `flow.add` and `flow.reset`, which throw `PluginRpcException` for what the script should show.

`ui/flow.js` is a React component that imports `@xyflow/react` and gets the one the window runs, with its stylesheet and the colors of the window in both themes. It draws each step as a custom node (`nodeTypes`, defined outside the component), colors the links with `useTheme()`, animates the ones into a running step, and adds `Background`, `Controls`, `MiniMap` and two `Panel`s with Blueprint cards: the counts of the steps, and the selected step with its buttons. React Flow keeps a copy of the graph (`useNodesState`, `useEdgesState`) so that a drag is smooth; the end of a drag, a new link and a removed one are calls to the plugin, whose answer comes back on the stream to every open tab.

`alta flow open` opens the tab; `alta flow status --step dotnet-tests --status done` moves a step on from a terminal or an agent, and the tab shows it at once. `alta canvas read` gives an agent the steps and their status. The pipeline is the same at every start, so the canvas looks the same each time: **Reset** brings it back.
